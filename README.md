# WP Simple Access Control

![Version](https://img.shields.io/badge/version-0.1.0-blue)
![License](https://img.shields.io/badge/license-GPL--2.0--or--later-green)
![PHP](https://img.shields.io/badge/PHP-8.1%2B-777bb4)
![WordPress](https://img.shields.io/badge/WordPress-6.4%2B-21759b)

Restrict access to single contents (pages, posts and any public custom post type) **and to single blocks** by user role, with an inline login form, an access log and multisite support.

> Work in progress: the full documentation and the screenshots are added at the end of the development.

## Requirements

- PHP 8.1 or higher
- WordPress 6.4 or higher
